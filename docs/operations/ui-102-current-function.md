待处理 PKCE 数据在 sessionStorage 中最多保留10分钟，回调同步消费一次，包含拒绝路径；旧版本缺时间戳数据拒绝后重新登录。return path 仅站内无参数路径。token POST 与 BFF session POST 各自15秒超时，无自动重试；中断或超时的服务端执行结果可能未知，须重新建立身份，不能把前端内存清空解释成服务端登出。token 与长期密钥不进入内存会话元数据或存储。新登录、回调开始、401清空旧元数据；代次检查阻止迟到响应恢复已清空的客户端身份，服务端会话及撤销仍由BFF负责。

有效subject和正数有效期为成功前置；真实模式还要求短期token并收到BFF session的204响应。MFA成功必须通过生成schema，401返回消毒的登录路由，错误不展示服务端私有详情。校验失败清空验证码；有效期、锁定和重试策略以身份服务为准。403/404采用同一不可探测资源文案，维护禁写，网络恢复只引导重新验证，不自动重放写入。
