# ADR: TP13 Loong 专项评估退役

## 状态

已退役，2026-10-01。保留本 ADR 作为历史决策记录。

## 决策

Loong 未集成到 QuantOS：没有引入其运行时依赖、上游类型或业务功能。此前仅作设计参考，候选设计不构成采纳承诺。

停止 Loong 专项评估，将 TP13 从后续交付、复审和验收范围移除；删除参考目录、专项测试和进度台账。此前面向 F07、U 系列和 X02 的候选采纳及上游重评估事项不再作为待办。

## 影响

QuantOS 自有的会话、权限、工作流、审批和审计能力继续保留。历史审计证据及构建工具链中的 LoongArch 平台依赖保持原样。

未来如需重新引入 Loong，应另立任务和 ADR，重新评估依赖、许可证及安全边界。
