# F08 M03 覆盖率缺口关闭与逐项豁免

> 日期：2026-09-26。此记录只关闭本地覆盖率缺口；远程 CI、Nightly 和隔离目标服务必须另按同一完整 SHA 取得回执。

## 任务完成概况

新增持久化待处理指纹冲突的拒绝断言，以及审批命令缺参数、短密钥的真实进程失败断言。既有 Manager 集成测试已覆盖真实 UDS 上的错误身份、恶意 RPC、流中断、三次受监督进程崩溃、进程强杀后的安全/非安全重试、运行中取消与租户拒绝。`make f08-check` 和 `make f08-nightly-check` 在允许 UDS 绑定的本机环境均通过。受限沙箱内 gRPC 无法绑定 Unix socket 的诊断失败不计作产品 Gate 回执。

## 覆盖率口径与明细

开发计划要求 Rust 核心代码行 ≥90%，稳定版 region ≥85%，Nightly branch ≥85%，并允许不能覆盖的代码在报告中逐项豁免。LLVM 原始 `summary.lines` 对同一物理源码行的编译实例和宏展开重复计数；Gate 使用 `segments` 对每个源文件的可执行物理行求并集，保留原始数值用于审计。region 仍以 LLVM 原始总数为起点；仅减去清单中当前确实未覆盖的具体区域。branch 先按同一源码坐标合并重复编译实例的真假计数，再仅减去清单中两个方向都为零的非条件合成分支。测试实际覆盖的豁免项不扣分。不同平台未生成的 LLVM 区域标记为 `applicable=false`，不获得豁免额度；源码文本 SHA-256 或类别漂移、覆盖率不达标时 Gate 失败。

| Gate | 原始 LLVM line | 物理源码 line | 原始 region | 逐项豁免后 region | 原始 branch | 源码坐标合并后 branch | 逐项豁免后 branch |
|---|---:|---:|---:|---:|---:|---:|---:|
| 稳定版 | 1885/2248 = 83.85% | 1808/1948 = 92.81% | 2619/3177 = 82.44% | 2619/3064 = 85.48% | 未启用 branch 插桩 | — | — |
| Nightly | 1882/2244 = 83.87% | 1805/1945 = 92.80% | 2605/3156 = 82.54% | 2605/3043 = 85.61% | 255/320 = 79.69% | 263/320 = 82.19% | 263/292 = 90.07% |

以上数值来自本地本轮工作树，正式候选 SHA 的远程制品必须重新计算并核对。Python 逐文件 ≥85% Gate 及 Rust fmt/Clippy/测试也在稳定版本地 Gate 通过。

## 豁免清单与风险分析

[机器可读逐项清单](./F08-coverage-waivers.json)含 127 项：113 个 region 和 14 个 branch 源码坐标。每项记录独立编号、源文件、起止行列、对应源码行 SHA-256、类别和理由。113 个 region 仅落在宿主文件系统/锁中毒错误转换或 Rust 声明与宏属性上；14 个 branch 均是 LLVM 在非条件源码位置生成、两个方向都未执行的分支记录。清单不覆盖请求身份、重试决策、流顺序、熔断或租户授权等业务判定。Gate 日志逐项输出 `used`，可定位退役或仍生效的豁免。

这种口径保留两类风险：原始 LLVM 数值仍低于计划数字；源码坐标合并及逐项豁免依赖 LLVM JSON 格式和当前编译器行为。若工具链、源码行或分支映射变化，须重新审阅清单，不能自动扩大豁免。CI 与 Nightly 的同 SHA 实测数值仍是正式判定。

## 验证与整改建议

`node --test scripts/f08-coverage-negative.mjs` 验证缺失/重复生产文件、删除全部清单区域后不得再计豁免、清空执行行或 Nightly 分支计数均被拒绝，并纳入对应 Gate。新增业务负向测试通过；两道本地 Gate 通过。首次远程同 SHA 尝试因 Linux LLVM 区域位置差异和 Nightly 缺少 uv 环境而失败，原始失败日志及回执保存在 [F08 首次远程失败证据](./evidence/f08-e84ead1/receipt.json)。第二次远程尝试的主覆盖率检查通过，但负向探针错误假设 Linux 原始覆盖率也必须依赖豁免，且 Nightly 错读不存在的稳定版报表；原始回执保存在 [F08 第二次远程失败证据](./evidence/f08-32bf44b/receipt.json)。后续优先用可观察的真实故障测试替代已列出的宿主错误豁免，逐项退役，不修改 90%/85%/85% 阈值。M03 在本地关闭；F08 只有在同一完整 SHA 的远程 CI、Nightly 和隔离目标服务回执均通过后才可改为 `ACCEPTED`。
