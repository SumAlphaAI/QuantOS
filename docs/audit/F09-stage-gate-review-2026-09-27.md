# F09 阶段 Gate 适配性复核（2026-09-27）

## 结论

**存在阶段误置。**F09 任务名为“本地可观测性、容量阈值与故障注入”，但此前远程目标工作流把“九类真实指标最近 90 秒均有样本”设为必过 Gate。当前服务尚未部署，四类指标的业务来源也尚未交付；在此阶段，即使源码、规则和数据库组件均正确，该 Gate 也必然失败。`1809541e82b464602f93e67d89adec3660a2f9e5` 的目标组件回执 `PASS / f09Accepted=false`，同 SHA 来源覆盖回执 `FAIL`（九类均无近期样本），直接验证了这个错位。

本次**从 F09 开发期必过工作流移除九类在线来源覆盖检查**，保留可在项目早期真实运行的源码、规则、数据库组件与本地 Engine 故障检查。上线后才能执行的来源密度、持续告警、通知和跨服务同链故障，列为 L04 上线前验收。此范围调整不表示这些运行期要求已通过，也不改变历史 22 点复核的原始证据。
