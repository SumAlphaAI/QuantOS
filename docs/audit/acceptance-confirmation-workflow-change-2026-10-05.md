# 验收人工确认流程调整（2026-10-05）

## 一、调整概况

按用户要求，所有原六方或其他多角色项目验收统一改为 **Codex 拟定完整文稿、项目用户一人确认、Codex 保存答复并执行门禁**。适用于 G0–G8、BFF/provider 最终验收、Beta/Live-readiness 和 Desktop D0–D4。含 Domain 的原七角色最终评审同样适用。

本次只授权流程变更，当前 G0 文稿尚未确认。原六方身份文件不再是当前确认前置；确认对象仍是具体文稿及其功能范围。owner 和各阶段技术要求保留。
